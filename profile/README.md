# NeoLeaf 🍃

**NeoLeaf.Science** is a free, open-source, collaborative LaTeX editor for students, researchers and academics.

- **Compiles in your browser.** pdfTeX, XeLaTeX and LuaLaTeX with BibTeX and Biber run as WebAssembly, with no queue and no time limit. An optional local agent compiles with your own TeX installation.
- **Your projects are yours.** Each project is a Git repository in your GitHub or Codeberg account. The server does not store your projects.
- **Real-time collaboration**, Git history, comments, SyncTeX and a catalog of journal and thesis templates.
